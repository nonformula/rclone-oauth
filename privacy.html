Privacy Policy

This application is a personal integration using rclone to access Google Drive.

Data Access

The application accesses Google Drive files with permission from the account owner.

Data Usage

Google Drive data is accessed and processed for personal file management purposes.

Data Storage

Authentication credentials are stored locally by rclone. Files may be transferred to local storage as directed by the account owner.

Data Sharing

This integration does not sell Google user data or intentionally share it with third parties.

Contact

This is a personal-use application. Contact the application owner through the support email shown on the Google authorization screen.
